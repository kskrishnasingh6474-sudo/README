# SOLAR-XR 🚀

**An interactive 3D space explorer controlled by hand gestures.**

SOLAR-XR is a curiosity-driven engineering experiment that explores a more natural way to interact with a 3D environment: using hand gestures instead of relying only on a keyboard or mouse.

## Project idea

Use real-time computer vision to interpret hand movements and translate them into interactions inside a 3D space environment.

## Technologies

- **MediaPipe Hand Landmarker** — real-time hand landmark detection through a webcam.
- **JavaScript gesture logic** — rule-based gesture recognition using landmark positions, distances, and ratios.
- **Three.js** — 3D rendering and interactive visualizations.
- **WebGL / WebGPU** — browser graphics technologies used for rendering.

## Described features

- Hand tracking through a webcam.
- Gesture recognition for open palm, fist, pinch, pointing, and peace sign.
- Particle-based planetary models and orbital systems.
- Visualizations of the Sun, Earth's internal layers, and the Milky Way.
- Gesture-driven object selection, rotation, zoom, and exploded views.

## Project note

SOLAR-XR is an experimental learning project, not a production AI product. Its main focus is the interaction pipeline: converting hand landmarks into meaningful gestures and translating those gestures into real-time visual changes.
